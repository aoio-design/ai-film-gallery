# Runtime Analysis & Padding Techniques

## Estimation Methodology

For screenplays in markdown-hybrid format, use the **1 page ≈ 1 minute** rule as baseline, then adjust:

| Factor | Adjustment | Rationale |
|--------|-----------|-----------|
| Dialogue-heavy scenes | +15-20% | Spoken words take longer than reading speed suggests |
| Action/montage sequences | -10-20% | Visual action compresses faster than dialogue |
| Voiceover/monologue | Neutral | Reads at roughly spoken pace |
| Scene description density | +5-10% per paragraph | Establishing shots + atmospheric details add screen time |
| Transition direction (e.g., "FADE TO BLACK") | +2-3s each | Each transition adds a beat |

**Process:**
1. Count scenes and estimate per-scene duration based on dialogue count and action density
2. Sum estimates with transitions
3. Give a range (low-end = tight editing, high-end = director's cut with generous pacing)
4. Flag episodes more than 2 minutes off target

## Padding Techniques for Under-Length Episodes

When a completed screenplay runs significantly under the target runtime:

### Technique 1: B-Plot Flashback Intercut

**When to use:** The episode has strong present-day content but lacks visual variety or background depth.

**How:**
1. Identify a moment in the present-day dialogue that references past events (a letter, a photo, a memory being described)
2. Cut to a flashback showing that event from the past character's POV
3. Structure as 2-3 short interleaved flashbacks (30-60s each), not one long one
4. Return to present with "BACK TO — CONTINUOUS"

**Effect:** Adds 2-4 minutes. Deepens character backstory without requiring additional dialogue. Creates visual variety (different location, different lighting, different era).

**Example:** A character mentions a warning letter; cut to the office where it was written, the campus where it was handed over, and home where it was read — three short flashbacks showing what the character only described.

### Technique 2: POV Vision / Internal Experience Sequence

**When to use:** A character is unconscious, experiencing a memory surge, or having a supernatural encounter. The present-day content is thin (one character alone in a room).

**How:**
1. Insert the vision sequence between the character losing consciousness and waking
2. Shoot entirely from the character's POV — the camera IS their eyes
3. Use visual degradation: soft focus, colour bleed, "vaseline on the lens"
4. Keep the content fragmentary: single images, whispery/subliminal audio, rapid FLASH cuts
5. Reveal 2-3 new puzzle pieces but never the full picture
6. End with a clear trigger to wake (a name, a warning, a face)

**Effect:** Adds 2-4 minutes. Advances the mystery without dialogue. Creates an immersive, subjective experience that dialogue scenes can't match.

**Example:** An unconscious character's vision — indistinct figures speaking in static-fragmented whispers, three FLASH cuts (a dead landscape, a recurring symbol, a wall of faces including a familiar one), ending with a whispered name that triggers waking.

### Technique 3: Solo Investigative Montage with Voiceover

**When to use:** One character is alone, studying evidence. No dialogue partner available.

**How:**
1. Character moves through evidence (photos, board, documents), flashlight or finger tracing connections
2. Internal voiceover — thinking out loud, testing theories, asking questions
3. Camera moves slowly across evidence, cutting to character's face reacting to realizations
4. Build from confusion → partial connection → frustrated dead end → new insight

**Effect:** Adds 1-3 minutes. Covers exposition visually. Shows the character's thought process instead of telling it through dialogue.
